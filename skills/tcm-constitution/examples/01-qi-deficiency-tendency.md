# 示例 1：欧洲客户的体质自评结果

> 虚构病例 / Fictional case

## 输入 Input

- questionnaire: 已完成标准问卷（英文对照版）
- language: 英语
- health_conditions: 无已知疾病

## 输出 Output

```
【Result】
| Constitution | Converted score | Outcome |
|---|---|---|
| Balanced (平和质) | 56 | No |
| Qi-deficient (气虚质) | 43 | Yes |
| Yang-deficient (阳虚质) | 34 | Tendency |
| Others | <30 | No |

【In plain words】In this framework, a qi-deficient constitution describes people who tire easily, may feel short of breath on exertion and catch colds more often. It is a description of tendencies, not an illness.

【Wellness direction】Regular sleep, moderate exercise you can sustain, warm cooked meals; avoid over-exertion.

【Referral】For herbal medicine or acupuncture, see a licensed TCM physician.

【Note】Constitution assessment is for wellness only, not a diagnosis.
```
