# 示例 1：日本患者第一次到北京医院门诊

> 虚构病例 / Fictional case

## 输入 Input

- hospital: 北京某三甲医院国际医疗部
- visit_type: 门诊
- patient_language: 日语，会少量英语
- has_escort: 无
- phone_plan: 已购 eSIM

## 输出 Output

```
【到院前清单 / Before you go】
☐ 护照原件 ☐ 预约确认（截图） ☐ 病历摘要中英文版 ☐ 既往影像光盘 ☐ 用药清单 ☐ 已绑定外卡的移动支付

【就医当天流程 / On the day】
1. 提前 30 分钟到国际医疗部前台，出示护照建档
2. 前台安排就诊，若需检查，按指引缴费后去检查科室
3. 检查报告出具时间问清楚，是否可线上查看
4. 复诊时间当场确认

【缴费与发票 / Paying】国际部前台或自助机缴费；保留发票用于保险

【常用语卡 / Phrase card】
| 日本語 | 中文 | 拼音 |
|---|---|---|
| 予約があります | 我有预约 | wǒ yǒu yùyuē |
| ペニシリンにアレルギーがあります | 我对青霉素过敏 | wǒ duì qīngméisù guòmǐn |
| 痛いです（10段階で7） | 我很疼，10 分里 7 分 | wǒ hěn téng, shí fēn lǐ qī fēn |

【紧急信息 / Emergency】急救 120；日本驻华使馆联系方式请查官网
```
