# 示例 2：新西兰患者自费后回国报销

> 虚构病例 / Fictional case

## 输入 Input

- payer: 保险事后报销
- insurer: 新西兰某旅行加医疗保险
- hospital: 成都某医院
- estimated_amount: 约 30,000 CNY
- payment_tools: 万事达借记卡；已安装两款常用移动支付应用

## 输出 Output

```
【付款方案 / Payment plan】
| 阶段 | 金额 | 方式 | 需提前准备 |
|---|---|---|---|
| 门诊 | 小额 | 移动支付（已绑定外卡） | 出发前完成绑卡与实名 |
| 住院预交金 | 向医院确认 | 借记卡刷卡 | 提前告知银行境外大额消费 |

【保险 / Insurance】先确认保单是否覆盖择期就医（旅行险通常只覆盖意外与急症，以保单原文为准）。
【理赔材料清单 / Claim pack】☐ 发票原件 ☐ 费用明细 ☐ 出院小结英文翻译 ☐ 付款记录截图
【时限 / Deadlines】按保单规定的递交期限，回国后尽快递交
【待确认 / To confirm】保单是否覆盖择期治疗
```
