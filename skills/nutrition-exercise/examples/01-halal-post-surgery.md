# 示例 1：清真饮食患者胃部手术后在华恢复

> 虚构病例 / Fictional case

## 输入 Input

- recommendations: 医生：少量多餐，软食，避免辛辣，术后 4 周内不提重物
- restrictions: 清真
- location: 上海，酒店式公寓可做饭
- activity_level: 可室内行走

## 输出 Output

```
【约束 / Constraints】少量多餐；软食；清真；避免辛辣；4 周内不提重物

【一周饮食 / Weekly meals】（示例两天）
| 时间 | 第 1 天 | 第 2 天 |
|---|---|---|
| 早 | 小米粥、蒸蛋 | 燕麦粥、香蕉 |
| 加餐 | 酸奶（清真认证） | 蒸南瓜 |
| 午 | 清炖牛肉（清真餐厅外带，去辣）、软米饭 | 鸡肉末豆腐羹 |
| 晚 | 番茄鸡蛋面（少油） | 鱼片粥 |

【点餐卡 / Ordering card】
请不要放辣椒，少油少盐，做软一点。我只吃清真食品。

【活动计划 / Activity】每天室内或小区平地散步，按医生允许逐步增加；不提超过医生规定重量的物品
【停止信号 / Stop and call】腹痛加重、发热、呕吐、黑便时立即联系医生
```
