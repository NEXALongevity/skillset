# 家属陪同指南 · Family Companion Guide

## 用途 · Purpose

给陪同患者来华的家属一份指南：家属能做什么、不能代替患者做什么；知情同意与授权；病房陪护规定；家属自己的住宿、饮食与休息；钱和证件；紧急情况怎么办。

A guide for family members accompanying a patient to China: what they can and cannot do on the patient's behalf, consent and authorisation, ward rules, their own accommodation, food and rest, money and documents, and emergencies.

## 何时使用 · When to use

- 确定有家属陪同后、出发前
- 入院当天
- 患者无法自行表达意愿时

## 输入 · Inputs

| 字段 Field | 说明 Description | 必需 Required |
|---|---|---|
| relationship | 与患者关系 | 是 |
| patient_capacity | 患者能否自行决定与签字 | 是 |
| stay_length | 陪同天数 | 是 |
| language | 家属语言 | 是 |

## 步骤 · Steps

1. **角色**：陪伴、沟通协调、生活照料；医疗决定由有决定能力的患者本人做出。
2. **授权**：患者可能无法签字时，提前了解医院对授权委托书的要求（向医院确认，必要时在本国办理公证认证）。
3. **病房规则**：探视与陪护规定、能否留宿、陪护床、餐食，以病区规定为准。
4. **照顾自己**：住处、轮换休息、心理支持渠道。
5. **钱和证件**：护照与复印件分开放；预交金与发票由谁保管。
6. **紧急情况**：急救 120、病区护士站、使领馆。

## 输出格式 · Output format

```
【您的角色 / Your role】
【授权与签字 / Consent】
【病房规则 / Ward rules】（待医院确认）
【照顾自己 / Look after yourself】
【证件与钱 / Documents & money】
【紧急情况 / Emergency】
```

## 边界与禁止事项 · Boundaries

- 不建议家属替有决定能力的患者做医疗决定。
- 授权文件的法律效力以医院和律师意见为准。
- 不替家属隐瞒或改变医生的信息。
