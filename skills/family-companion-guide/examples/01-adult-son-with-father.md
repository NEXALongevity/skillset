# 示例 1：儿子陪父亲来华做心脏手术

> 虚构病例 / Fictional case

## 输入 Input

- relationship: 儿子
- patient_capacity: 父亲可自行决定与签字
- stay_length: 21 天
- language: 英语

## 输出 Output

```
【您的角色 / Your role】陪伴、协调、照料。手术同意书由您父亲本人签署，口译在场逐条翻译。
【授权与签字 / Consent】如担心术后短期内父亲无法签字，提前询问医院是否需要授权委托书及格式要求
【病房规则 / Ward rules】心外科术后可能先入监护病房，探视时间以医院规定为准
【照顾自己 / Look after yourself】21 天较长，安排固定休息时间
【紧急情况 / Emergency】急救 120；病区护士站电话；所在国使领馆（查官网）
```
