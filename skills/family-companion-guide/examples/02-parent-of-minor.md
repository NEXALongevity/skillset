# 示例 2：父母陪未成年孩子就医

> 虚构病例 / Fictional case

## 输入 Input

- relationship: 母亲
- patient_capacity: 患者 12 岁，未成年
- stay_length: 10 天
- language: 泰语

## 输出 Output

```
【授权与签字 / Consent】未成年人由监护人签署同意；带孩子出生证明或监护关系证明（向医院确认是否需要翻译与认证）
【病房规则 / Ward rules】儿科病房通常允许一名家长陪护，以医院规定为准
【照顾自己 / Look after yourself】向医院了解儿科病房的家长休息与餐食安排
```
