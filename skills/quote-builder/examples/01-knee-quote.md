# 示例 1：膝关节置换报价单

> 虚构内容 / Fictional content

## 输入 Input

- cost_items: 手术及住院 95,000–120,000 CNY（医院报价 2026-11-20）；住宿、口译估计 13,500 CNY
- service_fee: 全程协调服务费 12,000 CNY（含预约、翻译摘要、行程、陪诊 3 次）
- validity: 30 天
- payment_terms: 服务费签约付 50%，到院付 50%；医疗费直接付给医院
- commission_disclosure: 不收取医院佣金

## 输出 Output

```
【报价单 / Quotation】Q-2026-001 · 2026-11-27 · 有效期至 2026-12-27

| 类别 | 项目 | 金额 (CNY) | 说明 |
|---|---|---|---|
| 医疗费 | 手术及住院 7 天（含假体） | 95,000 – 120,000 | 医院报价，以医院结算为准，直接付给医院 |
| 行程费 | 住宿、口译 | 约 13,500 | 估计，按实际 |
| 服务费 | 全程协调 | 12,000 | 含预约、病历摘要翻译、行程规划、陪诊 3 次 |

【包含 / Included】上表所列
【不包含 / Not included】机票、出院后复查、康复治疗、并发症处理与延长住院费用、签证费
【付款与退款 / Payment & refunds】服务费签约付 50%，到院付 50%；行前取消退还已付服务费的…（按合同约定）
【披露 / Disclosure】NEXA 不从医疗机构收取佣金
【签字确认 / Acceptance】患者签字 / 日期
```
