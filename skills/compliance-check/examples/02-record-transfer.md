# 示例 2：跨境发送病历

> 虚构病例 / Fictional case

## 输入 Input

- content_type: data-transfer
- patient_region: 德国 Germany
- consent_status: unknown

```
准备把患者（德国籍，52 岁）的完整病历 PDF、护照扫描件和 PET-CT 影像通过微信发给北京某医院国际部的医生，请他评估是否适合质子治疗。
```

## 输出 Output

```
【检查结论 / Result】暂停发送

【逐项结果 / Checklist】
| 编号 | 检查项 | 结果 | 说明 |
|---|---|---|---|
| 1 | 最小必要 | 风险 | 评估治疗适应证不需要护照扫描件 |
| 2 | 跨境数据同意 | 风险 | 未确认患者书面同意 |
| 3 | 适用法规 | 风险 | 患者在欧盟，涉及 GDPR 对健康数据的特殊保护 |
| 5 | 医疗决定说明 | 通过 | 由医院医生评估 |
| 7 | 医学声明 | 不适用 | |

【修改建议 / Suggested fixes】
- 先取得患者书面同意，写明接收方（医院名称）、用途（治疗评估）、数据范围和保存期限
- 只发送评估所需材料：病历摘要、病理报告、PET-CT 影像；不发护照
- 改用医院国际部指定的正式渠道（如加密邮箱或医院平台）传输，避免个人社交软件
- 发送前用"病历整理与医学翻译"Skill 生成标准摘要

【适用法规提示 / Regulations to consider】
- 中国《个人信息保护法》（敏感个人信息、单独同意）
- 欧盟 GDPR（健康数据属于特殊类别数据，跨境传输有专门要求）

【提醒 / Note】本检查为自检工具，重大事项请咨询律师。
```
