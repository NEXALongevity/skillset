# 示例 2：在华开具中成药后回国核对

> 虚构病例 / Fictional case

## 输入 Input

- medications: 二甲双胍 500 mg 每日两次
- supplements: 在华医生开具的某中成药（说明书注明成分）
- sources: 中成药说明书、本国药师

## 输出 Output

```
【可能的相互作用 / Possible interactions】
| 组合 | 等级 | 来源 | 需要确认的问题 |
|---|---|---|---|
| 二甲双胍 + 中成药 | 说明书未提及；药学数据库未查到报道 | 说明书（2026-11-27 查） | 回国后本地药师是否同意继续使用；该中成药在本国是否可合法携带和购买 |

【给药师/医生的问题 / Questions】带说明书原件和中文成分表的英文翻译给本地药师
【提醒】未查到报道不等于没有相互作用
```
