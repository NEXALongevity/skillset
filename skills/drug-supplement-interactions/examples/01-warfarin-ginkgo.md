# 示例 1：长期服用抗凝药、计划在华手术的患者

> 虚构病例 / Fictional case

## 输入 Input

- medications: 华法林 3 mg 每日一次
- supplements: 银杏叶提取物；鱼油；某复方中成药（成分不明）
- planned_treatment: 髋关节置换

## 输出 Output

```
【用药清单 / List】
| 类别 | 名称 | 成分 | 剂量 | 状态 |
|---|---|---|---|---|
| 处方药 | 华法林 | 华法林 | 3 mg qd | 已核 |
| 补充剂 | 银杏叶提取物 | 银杏叶提取物 | 按包装 | 已核 |
| 补充剂 | 鱼油 | ω-3 脂肪酸 | 按包装 | 已核 |
| 中成药 | 某复方 | 成分待核 | — | 无法核查 |

【可能的相互作用 / Possible interactions】
| 组合 | 等级 | 来源 | 需要确认的问题 |
|---|---|---|---|
| 华法林 + 银杏叶 | 已知存在相互作用报道（出血风险） | 药品说明书 / 药学数据库（填写具体名称与查询日期） | 是否需要停用银杏叶、何时停 |
| 华法林 + 鱼油 | 已知存在报道 | 同上 | 同上 |
| 华法林 + 复方中成药 | 无法核查 | — | 请带原包装给药师查看 |

【给药师/医生的问题 / Questions】
1. 手术前华法林如何调整、是否需要桥接（由手术医生决定）？
2. 补充剂和中成药是否需要术前停用？

【提醒】任何停药、换药以医生或药师意见为准
```
