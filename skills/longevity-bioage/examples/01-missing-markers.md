# 示例 1：指标不全时的处理

> 虚构病例 / Fictional case

## 输入 Input

- chronological_age: 56
- biomarkers: 白蛋白、肌酐、血糖、C 反应蛋白、白细胞计数（缺淋巴细胞百分比、平均红细胞体积、红细胞分布宽度、碱性磷酸酶）
- method: 基于常规血液指标的表型年龄（需写明文献）

## 输出 Output

```
【方法 / Method】基于常规血液指标的表型年龄方法；所需指标以原文献为准；局限：基于特定人群数据建立，实验室方法差异会影响结果，不能用于个体诊断

【数据核对 / Data check】
| 指标 | 状态 |
|---|---|
| 白蛋白、肌酐、血糖、C 反应蛋白、白细胞计数 | 已有 |
| 淋巴细胞百分比、平均红细胞体积、红细胞分布宽度、碱性磷酸酶 | 缺失 |

【结果 / Result】不计算：指标不全
【给客户的说明 / Client note】缺失的 4 项属于常规血常规和肝功能项目，下次抽血时一并检测即可
```
