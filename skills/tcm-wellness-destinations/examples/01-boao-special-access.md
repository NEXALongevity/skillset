# 示例 1：中东客户询问博鳌乐城特许药械

> 虚构病例 / Fictional case

## 输入 Input

- interest: 特许药械
- nationality: 科威特
- duration: 3 周
- health_status: 在本国确诊某疾病，听说某境外新药在国内未上市

## 输出 Output

```
【需求归类 / Need】特许药械使用，属于医疗行为

【推荐方向 / Options】
| 目的地 | 提供什么 | 适合 | 政策要点（需核实） | 来源 | 核实日期 |
|---|---|---|---|---|---|
| 海南博鳌乐城国际医疗旅游先行区 | 区内指定医疗机构按规定使用部分境外已上市药械 | 医生评估认为有临床需要的患者 | 具体药品是否在可用范围、审批流程与时间 | 先行区管理部门官网（填写链接） | 待核实 |

【入境提示 / Entry】科威特在国家移民管理局公布的海南 30 天免签国家范围内需核实；就医目的是否适用请向使领馆确认（visa-entry-policy）

【下一步 / Next】先由 second-opinion-prep 整理病历，交区内医疗机构医生评估是否适用；评估前不承诺"可以使用"。
```
