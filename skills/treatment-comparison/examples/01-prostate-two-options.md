# 示例 1：前列腺癌两个方案的对照

> 虚构病例 / Fictional case

## 输入 Input

- options: 方案 A（本国医生，2026-10）：根治性前列腺切除；方案 B（中国医生远程会诊，2026-11）：放射治疗
- quotes: 方案 B 医院报价 120,000–150,000 CNY
- patient_priorities: 治疗总时间、离家时间

## 输出 Output

```
【方案对照 / Side by side】
| 维度 | 方案 A：手术（本国） | 方案 B：放疗（中国） |
|---|---|---|
| 来源 | 本国泌尿外科，2026-10 | 中国放疗科远程会诊，2026-11 |
| 治疗周期 | 以医生说明为准 | 以医生说明为准（放疗通常分多次进行） |
| 离家时间 | 本国就医 | 需在华停留整个疗程 |
| 费用 | 本国医保或自费，向本国医院索取 | 120,000–150,000 CNY（书面报价） |

【问医生的问题 / Questions】
1. 我的分期与身体情况更适合哪种方式？各自的主要风险？
2. 放疗的具体次数与周期？能否部分在本国完成？
3. 两种方式之后的随访安排？

【说明】方案选择由患者与医生共同决定
```
