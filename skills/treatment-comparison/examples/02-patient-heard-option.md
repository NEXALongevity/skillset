# 示例 2：患者听说的方案

> 虚构病例 / Fictional case

## 输入 Input

- options: 方案 A（中国医生）：标准化疗；患者在网上看到某"新疗法"
- patient_priorities: 效果

## 输出 Output

```
【方案对照 / Side by side】
| 维度 | 方案 A：标准化疗 | 网上看到的疗法 |
|---|---|---|
| 来源 | 中国肿瘤科医生，2026-11 | 未经医生提出 |

【问医生的问题 / Questions】请主治医生评估网上看到的疗法是否适用于您、是否有获批或临床试验途径
【说明】未经医生提出的方案不作为选项比较
```
