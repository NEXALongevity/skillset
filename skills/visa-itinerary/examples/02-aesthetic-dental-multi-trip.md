# 示例 2：种植牙分次行程

> 虚构病例 / Fictional case

## 输入 Input

- nationality: 马来西亚护照
- departure_city: 吉隆坡
- hospital / city: 广州某口腔专科医院
- treatment_plan: 第一次：检查与种植体植入（约 3 天）；第二次：3 至 6 个月后安装牙冠（约 3 天）
- mobility: 正常
- budget_level: 经济

## 输出 Output

```
【入境方式 / Entry options】（以官方最新公布为准）
- 两次行程各约 4 至 5 天。核实马来西亚护照当前是否适用免签入境及单次停留上限；如不适用，按需申请签证
- 两次行程间隔 3 至 6 个月，需分别核实入境时的政策

【材料清单 / Document checklist】
☐ 护照（剩余有效期 6 个月以上）
☐ 医院预约确认
☐ 近期口腔 X 光或 CBCT（如有）
☐ 用药与过敏清单
☐ 往返机票、住宿预订

【行程 / Itinerary】
第一次（植入）
| 第几天 | 安排 | 备注 |
|---|---|---|
| 1 | 吉隆坡飞广州，入住 | |
| 2 | 口腔检查、影像 | |
| 3 | 种植体植入 | 术后饮食按医嘱 |
| 4 | 复查 | 由医生确认可以返程 |
| 5 | 返程 | |

第二次（安装牙冠，3 至 6 个月后，以医生通知为准）
| 第几天 | 安排 |
|---|---|
| 1 | 抵达广州 |
| 2 | 取模或扫描 |
| 3 | 戴冠、调整 |
| 4 | 返程（若需再次调整，预留 1 天） |

【待确认 / To confirm】
- 第二次就诊的具体间隔，取决于骨结合情况
- 牙冠制作周期，是否需要第二次行程延长
```
