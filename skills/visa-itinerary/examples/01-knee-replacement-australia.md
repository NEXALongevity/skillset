# 示例 1：澳大利亚患者赴上海做膝关节置换

> 虚构病例 / Fictional case

## 输入 Input

- nationality: 患者澳大利亚护照；陪同人（配偶）澳大利亚护照
- departure_city: 悉尼
- hospital / city: 上海某三甲医院骨科（国际医疗部）
- treatment_plan: 3 月 9 日门诊与术前检查；3 月 10 日入院；3 月 12 日手术；术后住院约 7 天；出院后第 7 天复查伤口
- mobility: 正常（术后需助行器）
- companions: 1
- budget_level: 舒适

## 输出 Output

```
【入境方式 / Entry options】（以中国驻澳使领馆和国家移民管理局最新公布为准）
- 选项 A：申请签证，停留期覆盖约 4 周
- 选项 B：若届时澳大利亚护照仍适用单方面免签，需核实单次停留上限是否覆盖全部行程（本行程约 25 天）
- 建议：行程较长且有术后不确定性，优先考虑签证，或确认免签停留期留有余量

【材料清单 / Document checklist】
☐ 护照（入境时剩余有效期 6 个月以上）× 2
☐ 签证申请材料（如选择签证）
☐ 医院预约确认或邀请函（向国际医疗部申请）
☐ 中英文病历摘要与近期影像
☐ 旅行或医疗保险证明（确认是否覆盖境外择期手术）
☐ 往返机票、住宿预订
☐ 用药清单（含正在服用的抗凝药，如有）

【行程 / Itinerary】
| 日期 | 第几天 | 安排 | 地点 | 备注 |
|---|---|---|---|---|
| 3/7 | 1 | 悉尼飞上海，入住酒店 | 酒店 | 不安排就诊 |
| 3/8 | 2 | 休息、熟悉医院路线、开通支付 | 医院周边 | |
| 3/9 | 3 | 门诊 + 术前检查 | 医院国际医疗部 | 空腹要求向医院确认 |
| 3/10 | 4 | 入院 | 医院 | 准备预交金 |
| 3/12 | 6 | 手术 | 医院 | |
| 3/13–3/19 | 7–13 | 住院康复 | 医院 | 陪同人住酒店或陪护（向医院确认） |
| 3/19 | 13 | 出院，回酒店 | 酒店 | 准备助行器，确认酒店无障碍 |
| 3/20–3/25 | 14–19 | 恢复、按医嘱康复训练 | 酒店 | |
| 3/26 | 20 | 伤口复查 | 医院 | 出院后第 7 天 |
| 3/26–3/30 | 20–24 | 缓冲期 | 酒店 | 由医生确认可以长途飞行 |
| 3/31 | 25 | 返程悉尼 | | 申请航空公司特殊协助（如需要轮椅） |

【住宿与交通 / Stay & transport】
- 选医院附近、有电梯和无障碍设施的酒店，距离以打车 10 分钟内为宜（待确认）
- 支付：准备可在中国使用的国际信用卡，或在移动支付应用中绑定外卡
- 交通：术后乘出租车或医院接送，避免地铁高峰

【紧急信息 / Emergency】
- 中国急救电话：120
- 澳大利亚驻上海总领事馆：请查询官网获取最新地址与电话
- 医院国际医疗部：见本库医院档案

【待确认 / To confirm】
- 术后多久可以乘坐长途航班
- 陪同人能否在病房陪护
```
