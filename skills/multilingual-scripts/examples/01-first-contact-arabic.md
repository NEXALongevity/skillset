# 示例 1：首次沟通（阿拉伯语）

> 虚构内容 / Fictional content

## 输入 Input

- scenario: first-contact
- language: 阿拉伯语
- details: 顾问名 {顾问}，患者关心骨科

## 输出 Output

```
【场景 / Scenario】首次沟通

【话术 / Script】
| 中文 | العربية |
|---|---|
| 您好，我是 NEXA Longevity 的医疗顾问 {顾问}。感谢您的信任。 | مرحباً، أنا {顾问}، مستشار طبي في NEXA Longevity. شكراً لثقتكم. |
| 为了帮您找到合适的骨科医生，我需要先了解您的情况和近期检查报告。 | لمساعدتكم في إيجاد طبيب العظام المناسب، أحتاج أولاً إلى معرفة حالتكم وأحدث التقارير الطبية. |
| 最终的治疗建议会由医生给出，我负责协调和陪同。 | التوصية العلاجية النهائية يقدمها الطبيب، ودوري هو التنسيق والمرافقة. |

【使用提示 / Notes】阿拉伯语版本需母语审校后再固定为模板
```
