Skill library

8 个 Skills，即插即用。

每个 Skill 都是一个包含 SKILL.md 的目录：用途、输入、步骤、输出格式、边界与医学声明一应俱全，附虚构病例示例，兼作测试用例。

01 · Learn

中国医疗体系导览

China Healthcare Guide

用患者听得懂的语言，介绍中国的医院分级、医院类型、国际医疗部、就诊流程与付费方式，帮助第一次考虑来中国就医的患者和海外合作伙伴建立基本认识。

./skills/china-healthcare-guide →
01 · Learn

医生与机构档案查询

Hospital & Doctor Lookup

从本库经核实的知识库（data/hospitals/）中，按方向、城市、医院类型或排名检索医疗机构，返回带来源和核实日期的档案。v0.1 收录六个方向（中医除外）各前 10 家医院，取自复旦版专科声誉排行榜；中医、医生档案、民营医院和外资医院在 v0.2 加入。

./skills/hospital-lookup →
02 · Assess

病历整理与医学翻译

Medical Record Summary & Translation

把患者提供的零散、多语言病历（诊断书、检查报告、出院小结、用药清单）整理成一页标准病历摘要，中文在前、英文在后，让中国医生几分钟内看清病情与诉求，提高"接诊前病历材料一次通过率"。

./skills/medical-record-summary →
02 · Assess

初步需求评估

Initial Needs Assessment

在首次接触患者时，把病情、诉求、预算、时间、语言和出行条件梳理成一份标准需求档案，并按统一规则标出"适合推进 / 需补充信息 / 不建议跨境 / 紧急情况"，帮助顾问快速决定下一步。

./skills/needs-assessment →
03 · Match

医生与方案匹配

Doctor & Treatment Matching

根据患者的需求档案和病历摘要，从本库知识库中筛出 3 至 5 家候选机构，逐一说明匹配理由、需要确认的问题和信息来源，帮助顾问在 48 小时内给出有依据的候选方案。v0.1 只匹配到医院层面；医生档案在 v0.2 加入后，再细化到专家。

./skills/doctor-matching →
04 · Travel

签证与行程规划

Visa & Itinerary Planning

在医院与就诊时间初步确定后，为患者及陪同人生成入境材料清单和按天排列的就医行程，把就诊、检查、治疗、恢复与返程衔接起来，避免因签证或行程问题耽误就医。

./skills/visa-itinerary →
∞ · Always on

合规与风险检查

Compliance & Risk Check

在对外发送或发布之前，按统一清单检查内容与流程是否存在隐私、知情同意、医学边界和宣传用语方面的风险，并给出修改建议。它是自检工具，不替代律师或监管部门的意见。

./skills/compliance-check →
∞ · Always on

多语言沟通

Multilingual Communication

在中国医生、医院与国际患者之间，提供术语统一、语气得体的医学笔译与口译脚本。所有译名以 shared/glossary.yaml 为准，保证不同顾问、不同 Skill 的译法一致。

./skills/multilingual-communication →
Get started

两行命令，
顾问变专家团。

  1. 克隆仓库放进 Claude Code、Claude.ai 或任何支持 Agent Skills 的工具。
  2. 用自然语言描述病例AI 会按需调用对应 Skill，不需要记任何命令。
  3. 拿到可复核的结果每条医院信息都带来源与核实日期，可用 scripts/validate.py 校验。

Principles

专业，从边界开始。

每个 Skill 上线前都要通过医学审核与合规审核。

01 / SOURCED

来源可溯

医院与政策信息只用官方公开资料，逐条标注来源与核实日期。

02 / BOUNDED

守医学边界

只做信息整理与流程支持，不诊断、不推荐治疗，以执业医生意见为准。

03 / PRIVATE

隐私优先

最小必要原则，跨境传输前取得同意；仓库只用虚构病例。

04 / OPEN

开源署名

代码 Apache-2.0，内容 CC BY 4.0，自由使用，署名 NEXA Longevity。
