跨境医疗旅游 Skills 库
Medical Travel Skills for China

一套开源的 AI Skills，帮助跨境医疗从业人员为国际患者找到中国合适的医生、医院与治疗方案，并精准、及时地完成赴华就医。

Open-source AI Skills that help medical travel professionals guide international patients to the right hospitals and treatments in China.

Skills（8）

按患者旅程组织：了解 → 评估 → 匹配 → 就医，另有贯穿全程的支持。

了解 · Learn

中国医疗体系导览 · China Healthcare Guide

用患者听得懂的语言，介绍中国的医院分级、医院类型、国际医疗部、就诊流程与付费方式，帮助第一次考虑来中国就医的患者和海外合作伙伴建立基本认识。

了解 · Learn

医生与机构档案查询 · Hospital & Doctor Lookup

从本库经核实的知识库（data/hospitals/）中，按方向、城市、医院类型或排名检索医疗机构，返回带来源和核实日期的档案。v0.1 收录六个方向（中医除外）各前 10 家医院，取自复旦版专科声誉排行榜；中医、医生档案、民营医院和外资医院在 v0.2 加入。

评估 · Assess

病历整理与医学翻译 · Medical Record Summary & Translation

把患者提供的零散、多语言病历（诊断书、检查报告、出院小结、用药清单）整理成一页标准病历摘要，中文在前、英文在后，让中国医生几分钟内看清病情与诉求，提高"接诊前病历材料一次通过率"。

评估 · Assess

初步需求评估 · Initial Needs Assessment

在首次接触患者时，把病情、诉求、预算、时间、语言和出行条件梳理成一份标准需求档案，并按统一规则标出"适合推进 / 需补充信息 / 不建议跨境 / 紧急情况"，帮助顾问快速决定下一步。

匹配 · Match

医生与方案匹配 · Doctor & Treatment Matching

根据患者的需求档案和病历摘要，从本库知识库中筛出 3 至 5 家候选机构，逐一说明匹配理由、需要确认的问题和信息来源，帮助顾问在 48 小时内给出有依据的候选方案。v0.1 只匹配到医院层面；医生档案在 v0.2 加入后，再细化到专家。

就医 · Travel

签证与行程规划 · Visa & Itinerary Planning

在医院与就诊时间初步确定后，为患者及陪同人生成入境材料清单和按天排列的就医行程，把就诊、检查、治疗、恢复与返程衔接起来，避免因签证或行程问题耽误就医。

全程 · All stages

合规与风险检查 · Compliance & Risk Check

在对外发送或发布之前，按统一清单检查内容与流程是否存在隐私、知情同意、医学边界和宣传用语方面的风险，并给出修改建议。它是自检工具，不替代律师或监管部门的意见。

全程 · All stages

多语言沟通 · Multilingual Communication

在中国医生、医院与国际患者之间，提供术语统一、语气得体的医学笔译与口译脚本。所有译名以 shared/glossary.yaml 为准，保证不同顾问、不同 Skill 的译法一致。

如何使用 · How to use

每个 Skill 是一个包含 SKILL.md 的目录，可直接放入 Claude Code、Claude.ai 或其他支持 Agent Skills 的工具。

git clone https://github.com/NEXALongevity/skillset
cp -r skillset/skills/doctor-matching ~/.claude/skills/
