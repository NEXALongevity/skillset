报价单生成 · Quote Builder

用途 · Purpose

把 cost-estimate 整理好的费用项生成一份正式、双语、可签字确认的报价单：医疗费、行程费、服务费分开列；写清包含与不包含、有效期、付款节点和退款规则。合并首批规划中的"费用预估与报价"。

Turn the items from cost-estimate into a formal bilingual quote the patient can sign: medical, travel and service fees listed separately, with inclusions, exclusions, validity, payment milestones and refund terms.

何时使用 · When to use

  • cost-estimate 完成后、向患者或合作伙伴发正式方案时
  • 方案变化需要重新报价时

输入 · Inputs

字段 Field 说明 Description 必需 Required
cost_items cost-estimate 输出的分项与来源 是
service_fee NEXA 或顾问服务费及其构成 是
validity 报价有效期 是
payment_terms 付款节点与退款规则 是
commission_disclosure 是否从医疗机构收取佣金 是

步骤 · Steps

  1. 分三栏：医疗费（注明"以医院结算为准"）、行程费（估计）、服务费（固定或按项）。
  2. 包含与不包含：逐条写出，尤其是复查、康复、并发症处理、延长住院。
  3. 透明披露：服务费构成；是否从医疗机构收取佣金（compliance-check 第 4 项）。
  4. 条款：有效期、付款节点、取消与退款规则、价格变动处理。
  5. 双语排版：中文 + 患者语言，金额与币种一致。
  6. 发送前跑 compliance-check。

输出格式 · Output format

【报价单 / Quotation】编号、日期、有效期
| 类别 | 项目 | 金额 | 说明 |
【包含 / Included】【不包含 / Not included】
【付款与退款 / Payment & refunds】
【披露 / Disclosure】
【签字确认 / Acceptance】

边界与禁止事项 · Boundaries

  • 医疗费只能来自医院书面报价，并注明以医院结算为准。
  • 不隐藏佣金或附加费用。
  • 不以"限时优惠"等方式施压。

示例 · Examples

示例 1：膝关节置换报价单

虚构内容 / Fictional content

输入 Input

  • cost_items: 手术及住院 95,000–120,000 CNY（医院报价 2026-11-20）；住宿、口译估计 13,500 CNY
  • service_fee: 全程协调服务费 12,000 CNY（含预约、翻译摘要、行程、陪诊 3 次）
  • validity: 30 天
  • payment_terms: 服务费签约付 50%，到院付 50%；医疗费直接付给医院
  • commission_disclosure: 不收取医院佣金

输出 Output

【报价单 / Quotation】Q-2026-001 · 2026-11-27 · 有效期至 2026-12-27

| 类别 | 项目 | 金额 (CNY) | 说明 |
|---|---|---|---|
| 医疗费 | 手术及住院 7 天（含假体） | 95,000 – 120,000 | 医院报价，以医院结算为准，直接付给医院 |
| 行程费 | 住宿、口译 | 约 13,500 | 估计，按实际 |
| 服务费 | 全程协调 | 12,000 | 含预约、病历摘要翻译、行程规划、陪诊 3 次 |

【包含 / Included】上表所列
【不包含 / Not included】机票、出院后复查、康复治疗、并发症处理与延长住院费用、签证费
【付款与退款 / Payment & refunds】服务费签约付 50%，到院付 50%；行前取消退还已付服务费的…（按合同约定）
【披露 / Disclosure】NEXA 不从医疗机构收取佣金
【签字确认 / Acceptance】患者签字 / 日期
示例 2：给海外合作中介的体检套餐报价

虚构内容 / Fictional content

输入 Input

  • cost_items: 体检套餐 8,800 CNY（体检中心价目表 2026 版）
  • service_fee: 每位客户 1,500 CNY
  • validity: 2027-06-30
  • commission_disclosure: 体检中心向 NEXA 支付推荐费 5%

输出 Output

【报价单 / Quotation】P-2026-014 · 有效期至 2027-06-30
| 类别 | 项目 | 金额 (CNY) | 说明 |
|---|---|---|---|
| 医疗费 | 高端体检套餐 | 8,800 | 体检中心 2026 版价目表，以结算为准 |
| 服务费 | 预约、报告翻译与解读协调 | 1,500 / 人 | — |

【披露 / Disclosure】体检中心向 NEXA 支付推荐费（5%），已计入上表价格，客户无需另付；请合作方向客户同样披露
