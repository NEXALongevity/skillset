病历整理与医学翻译 · Medical Record Summary & Translation

用途 · Purpose

把患者提供的零散、多语言病历（诊断书、检查报告、出院小结、用药清单）整理成一页标准病历摘要，中文在前、英文在后，让中国医生几分钟内看清病情与诉求，提高"接诊前病历材料一次通过率"。

Turn scattered, multilingual records into a one-page standard summary (Chinese first, then English) that a Chinese doctor can review in minutes.

何时使用 · When to use

  • 向医院国际部或医生提交会诊、转诊申请之前
  • 运行"医生与方案匹配"之前
  • 患者陆续补充材料，需要更新摘要时

输入 · Inputs

字段 Field 说明 Description 必需 Required
records 病历文字或文件内容（可多份、多语言） 是
request 患者诉求：想看哪方面、期望的治疗或第二意见 是
consent_status 是否已取得患者同意整理和传输其健康数据 是

consent_status 不是 yes 时，先提示取得同意（参见 compliance-check），可以继续整理但输出中标注"未取得同意，暂不可发送"。

步骤 · Steps

  1. 清点材料：列出每份材料的类型、日期、语言、出具机构。
  2. 提取信息：按模板字段提取，只用材料中写明的内容。
  3. 统一术语：译名以 shared/glossary.yaml 为准；检查数值保留原单位，必要时括注换算。
  4. 时间线：按日期整理诊断与治疗经过。
  5. 缺失项：对照"医生通常需要的材料"列出缺失项，例如肿瘤需病理报告和分期、影像需原始 DICOM 文件。
  6. 去标识：摘要中只保留年龄、性别、国籍；姓名、证件号、联系方式不写入摘要正文。
  7. 双语输出：先中文，后英文，内容一致。

输出格式 · Output format

# 病历摘要 / Case Summary
材料来源：<n 份，最近日期 YYYY-MM-DD>   整理日期：YYYY-MM-DD   同意状态：<已取得/未取得>

## 一、基本信息
年龄 / 性别 / 国籍 / 常用语言

## 二、主诉与诉求
## 三、现病史（时间线）
| 日期 | 事件（诊断、检查、治疗） | 机构 |
## 四、关键检查结果
## 五、既往史、过敏史、用药史
## 六、已有诊断（原文 + 译文，注明出具机构）
## 七、缺失材料
## 八、待确认

边界与禁止事项 · Boundaries

  • 只整理和翻译，不下诊断、不推断分期、不解读影像。原文没有的结论一律不写。
  • 原文字迹不清、自相矛盾或单位不明时，写入"待确认"，不猜测。
  • 不在摘要正文中保留可识别身份的信息。
  • 示例与测试只用虚构病例。

医学声明 · Disclaimer

本摘要由 AI 辅助整理，仅供医生参考，不构成诊断；请以原始病历和执业医生意见为准。This summary is AI-assisted, for clinician reference only, and is not a diagnosis.

示例 · Examples

示例 1：泰国乳腺癌患者求第二意见

虚构病例 / Fictional case

输入 Input

  • consent_status: yes
  • request: "Second opinion on whether surgery or neoadjuvant therapy first; considering treatment in Guangzhou."
  • records（节选）:
  • Intake form: female, 47, Thai national, speaks Thai and English.
  • Mammogram report, Bangkok, 2026-09-02 (English): left breast mass 2.8 cm, BI-RADS 5.
  • Core biopsy pathology, 2026-09-10 (English): invasive ductal carcinoma, grade 2, ER 90%+, PR 60%+, HER2 1+, Ki-67 25%.
  • Clinic note (Thai), 2026-09-15: axillary ultrasound, one suspicious left axillary lymph node; surgeon recommends surgery.
  • Medications: metformin 500 mg twice daily. Allergy: penicillin (rash).

输出 Output

# 病历摘要 / Case Summary
材料来源：4 份，最近日期 2026-09-15   整理日期：2026-11-27   同意状态：已取得

## 一、基本信息
47 岁 / 女 / 泰国 / 泰语、英语

## 二、主诉与诉求
左乳肿物，已活检确诊。希望获得第二意见：先手术还是先行新辅助治疗；考虑赴广州治疗。

## 三、现病史（时间线）
| 日期 | 事件 | 机构 |
|---|---|---|
| 2026-09-02 | 乳腺 X 线：左乳肿物 2.8 cm，BI-RADS 5 类 | 曼谷某医院 |
| 2026-09-10 | 穿刺活检病理：浸润性导管癌 | 同上 |
| 2026-09-15 | 腋窝超声：左腋窝 1 枚可疑淋巴结；外科建议手术 | 同上 |

## 四、关键检查结果
- 病理：浸润性导管癌，组织学 2 级；ER 90%+，PR 60%+，HER2 1+，Ki-67 25%

## 五、既往史、过敏史、用药史
- 用药：二甲双胍 500 mg，每日 2 次
- 过敏：青霉素（皮疹）
- 既往史：材料未提及

## 六、已有诊断
- Invasive ductal carcinoma, left breast（左乳浸润性导管癌）— 曼谷某医院病理科

## 七、缺失材料
- 乳腺 MRI 或超声原始影像（DICOM）
- 腋窝淋巴结是否穿刺及结果
- 全身分期检查（如胸部 CT、骨扫描），如已做
- 糖尿病相关近期化验（如糖化血红蛋白）

## 八、待确认
- 泰文门诊记录中淋巴结大小未写明
- 二甲双胍的用药原因（推测为糖尿病，需患者确认）
