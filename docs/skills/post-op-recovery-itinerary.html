术后康复行程 · Post-operative Recovery Itinerary

用途 · Purpose

从出院到回国之间的康复安排：住哪里、康复治疗、伤口复查、警示信号、由医生确认是否适合乘机，以及回国交接。所有时间点以主刀医生和康复医生的书面意见为准。

Plan the stretch from discharge to flying home: where to stay, rehab sessions, wound checks, red flags, the surgeon's fitness-to-fly confirmation and the handover home, strictly following written instructions from the surgical and rehab teams.

何时使用 · When to use

  • 手术确定后，提前规划康复期
  • 出院当天更新行程
  • 康复进度变化、需要延长停留时

输入 · Inputs

字段 Field 说明 Description 必需 Required
procedure 手术名称与日期 是
discharge_orders 出院医嘱：复查时间、康复要求、活动限制 是
mobility 行动能力 是
return_flight 计划返程日期与航程时长 是

步骤 · Steps

  1. 住处：靠近医院、无障碍、有电梯；需要时安排护理或陪护。
  2. 日程：按医嘱排康复治疗、换药、拆线、复查。
  3. 警示信号：出院小结中列出的情况；没有列出时向医生索取。
  4. 乘机确认：返程前由医生书面确认可以乘机；需要轮椅或特殊协助时提前向航空公司申请；长途飞行的血栓预防措施由医生决定。
  5. 改期预案：医生不同意按期乘机时，改签与延住的方案。
  6. 交接：交给 return-followup-handover。

输出格式 · Output format

【康复日程 / Recovery schedule】
| 日期 | 术后第几天 | 安排 | 地点 | 备注 |
【警示信号 / Red flags】
【乘机确认 / Fit to fly】
【改期预案 / Plan B】

边界与禁止事项 · Boundaries

  • 不安排早于医生允许的乘机或活动。
  • 不给出康复训练的强度处方，按康复医生要求执行。
  • 警示信号出现时先就医。

示例 · Examples

示例 1：前交叉韧带重建术后

虚构病例 / Fictional case

输入 Input

  • procedure: 前交叉韧带重建，3 月 5 日
  • discharge_orders: 3 月 7 日出院；术后第 2 周拆线；每周 3 次康复治疗；拄拐 4 周
  • mobility: 拄拐
  • return_flight: 计划 3 月 22 日，航程 9 小时

输出 Output

【康复日程 / Recovery schedule】
| 日期 | 术后第几天 | 安排 | 地点 | 备注 |
|---|---|---|---|---|
| 3/7 | 2 | 出院，入住酒店 | 酒店 | 无障碍房，电梯 |
| 3/9、11、13 | 4–8 | 康复治疗 | 医院康复科 | 打车，拄拐 |
| 3/19 | 14 | 拆线 + 复查 | 医院 | 复查时请医生确认能否乘机 |
| 3/16、18、20 | 11–15 | 康复治疗 | 医院康复科 | |
| 3/22 | 17 | 返程（待医生确认） | — | 申请航空公司轮椅协助 |

【乘机确认 / Fit to fly】3/19 复查时请医生出具书面意见；血栓预防措施由医生决定
【改期预案 / Plan B】医生不同意时，机票改签到医生允许的日期，酒店续住
示例 2：出院医嘱不完整

虚构病例 / Fictional case

输入 Input

  • procedure: 腹腔镜胆囊切除
  • discharge_orders: 只写"一周后复查"
  • return_flight: 术后第 6 天

输出 Output

【乘机确认 / Fit to fly】出院医嘱未写明可乘机时间，且复查在返程之后。
【待确认 / To confirm】
1. 请医生确认术后第 6 天能否乘机
2. 复查能否提前到返程前，或改在本国做
【改期预案 / Plan B】医生确认前不要锁定不可改签的机票
