医生与机构档案查询 · Hospital & Doctor Lookup

用途 · Purpose

从本库经核实的知识库（data/hospitals/）中，按方向、城市、医院类型或排名检索医疗机构，返回带来源和核实日期的档案。v0.1 收录六个方向（中医除外）各前 10 家医院，取自复旦版专科声誉排行榜；中医、医生档案、民营医院和外资医院在 v0.2 加入。

Search the verified knowledge base in data/hospitals/ and return sourced profiles. v0.1 covers the top 10 hospitals in six directions (all but TCM) from the Fudan specialty reputation rankings; TCM, doctor profiles, private and foreign-invested hospitals come in v0.2.

何时使用 · When to use

  • "上海哪些医院的肿瘤科比较强？"
  • "Which hospitals in China are known for orthopedics?"
  • 为 doctor-matching 准备候选机构池

输入 · Inputs

字段 Field 说明 Description 必需 Required
direction oncology / cardio-cerebrovascular / reproductive / checkup-longevity / tcm / orthopedics / aesthetics 否
city / province 城市或省份 否
type public / private / foreign 否
keyword 专长关键词，如"质子""肝移植" 否
language 输出语言 是

至少提供 direction、city 或 keyword 中的一项。

步骤 · Steps

  1. 读取 data/hospitals/<direction>.yaml（未指定方向时读取全部文件）。
  2. 按条件筛选；按 ranking.rank 升序排列。
  3. 每条结果必须带出 source_list、source_url、verified_on。
  4. 若 verified_on 距今超过 12 个月，在该条后标注"信息可能过时，请复核"。
  5. 知识库里查不到时，明确说"本库 v0.1 暂未收录"，可以建议用户查阅公开名单，但不得根据模型记忆补充医院或医生。
  6. 按 language 输出，医院名同时给出中英文。

输出格式 · Output format

共找到 <n> 家（数据范围：本库 v0.1，<方向>）

| 排名 | 医院 | 城市 | 优势科室 | 国际部 | 来源与核实日期 |

说明：排名引自 <source_list>，仅反映该名单的评价，不代表本库推荐。
<标准医学声明>

边界与禁止事项 · Boundaries

  • 只返回知识库中的记录，不编造、不补充。
  • 不对医院做"最好""首选"之类评价；排名一律注明出处。
  • 不提供医院内部联系方式，只给官网或公开的国际部信息。

医学声明 · Disclaimer

本 Skill 仅提供公开信息检索，不构成就医推荐，一切以执业医生意见为准。This Skill returns public information only and is not a medical recommendation.

示例 · Examples

示例 1：上海的肿瘤专科医院

输入 Input

  • direction: oncology · city: 上海 · language: zh

输出 Output

共找到 1 家（数据范围：本库 v0.1，肿瘤学）

| 排名 | 医院 | 城市 | 优势科室 | 国际部 | 来源与核实日期 |
|---|---|---|---|---|---|
| 3 | 复旦大学附属肿瘤医院 Fudan University Shanghai Cancer Center | 上海 | 肿瘤学 | 本库暂未收录 | 复旦版 2023 年度专科声誉排行榜；2026-11-27 |

说明：排名引自复旦大学医院管理研究所《2023年度中国医院专科声誉排行榜》，仅反映该名单的评价，不代表本库推荐。本库 v0.1 只收录各方向前 10 家；上海其他设有肿瘤科的综合医院暂未收录，可查阅原榜单的提名医院。

本内容仅提供公开信息检索，不构成就医推荐，一切以执业医生意见为准。
示例 2：知识库未收录时

输入 Input

  • direction: tcm · language: en
  • keyword: "acupuncture for chronic back pain"

输出 Output

No results. Traditional Chinese medicine (TCM) hospitals are not yet included in v0.1 of this library: the public ranking used for v0.1 (Fudan specialty reputation rankings) has no TCM category, and we only list hospitals from a named public source.

TCM profiles are planned for v0.2. In the meantime, an advisor can check official sources such as hospital websites and national health authority announcements, and confirm details directly with the hospital.

This is public information only and not a medical recommendation.
