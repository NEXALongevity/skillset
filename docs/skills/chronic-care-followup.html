慢病随访 · Chronic Care Follow-up

用途 · Purpose

为高血压、糖尿病、肿瘤术后监测等慢病建立结构化随访计划：随访时间表、居家监测记录、需要立即就医的警示信号、给中国医生和本地医生的定期报告。计划内容以医生医嘱为依据，本 Skill 负责执行与提醒。

Set up and run a structured follow-up plan for chronic conditions such as hypertension, diabetes and post-cancer surveillance: schedule, home readings, red flags and periodic reports to the Chinese and local doctors. The plan follows physician orders; this Skill handles execution and reminders.

何时使用 · When to use

  • 在华治疗出院、回国后需要长期随访时
  • 患者在中国确诊慢病、需要与本地医生共同管理时
  • 随访数据需要定期整理给医生看时

输入 · Inputs

字段 Field 说明 Description 必需 Required
condition 疾病与当前治疗 是
physician_orders 医生给出的随访要求（项目、频率、目标值） 是
home_readings 居家监测数据（如血压、血糖） 否
local_doctor 本地医生是否已对接 否

步骤 · Steps

  1. 随访表：把医嘱拆成日历：复查项目、时间、在哪里做（本地还是返华）。
  2. 居家监测模板：按医嘱列出监测项和记录格式，目标值只写医生给出的数值。
  3. 警示信号：列出医嘱或出院小结中写明的需立即就医的情况；没有写明时提示患者向医生索取。
  4. 定期报告：按月或按随访节点汇总数据，生成给医生的中英双语简报（趋势、超出目标的次数、用药依从、患者问题）。
  5. 对接：与 return-followup-handover 衔接，确保本地医生拿到完整材料。

输出格式 · Output format

【随访日历 / Schedule】
| 时间 | 项目 | 地点 | 状态 |
【居家监测 / Home readings】
【警示信号 / Red flags】
【阶段报告 / Report to doctor】

边界与禁止事项 · Boundaries

  • 不调整药物剂量，不设定医生没有给出的目标值。
  • 数据异常只提示"联系医生"，不给处理建议。
  • 出现警示信号时，首先提示就近就医或拨打当地急救电话。

示例 · Examples

示例 1：高血压患者的月度随访简报

虚构病例 / Fictional case

输入 Input

  • condition: 高血压，服用氨氯地平
  • physician_orders: 每天早晚各测一次血压；目标 <130/80 mmHg（医生给出）；3 个月后复诊
  • home_readings: 30 天共 58 次读数，其中 9 次 ≥ 140/90

输出 Output

【随访日历 / Schedule】
| 时间 | 项目 | 地点 | 状态 |
|---|---|---|---|
| 每日 | 早晚血压 | 家中 | 进行中 |
| 第 3 个月 | 复诊 | 本地医生或远程 | 待预约 |

【阶段报告 / Report to doctor】
- 30 天读数 58 次（缺 2 次）
- 达到医生目标 <130/80：31 次；130–139/80–89：18 次；≥140/90：9 次，多在早晨
- 用药依从：患者自述 2 次漏服
- 患者问题：早晨偏高是否需要调整服药时间？（由医生判断）
示例 2：结肠癌术后监测计划

虚构病例 / Fictional case

输入 Input

  • condition: 结肠癌术后，辅助化疗已结束
  • physician_orders: 出院小结写明：术后 2 年内每 3 个月复查 CEA，每 6 个月腹盆 CT，1 年后肠镜
  • local_doctor: 已对接

输出 Output

【随访日历 / Schedule】
| 时间 | 项目 | 地点 | 状态 |
|---|---|---|---|
| 每 3 个月 | CEA | 本地 | 待安排 |
| 每 6 个月 | 腹盆 CT | 本地 | 待安排 |
| 术后 1 年 | 肠镜 | 本地或返华 | 待安排 |

【警示信号 / Red flags】以出院小结为准；出院小结未列出时，请向主治医生索取书面清单
【阶段报告 / Report to doctor】每次检查后 1 周内，把报告译文发给在华主治医生，提醒其回复是否需要调整计划
