治疗方案对比 · Treatment Option Comparison

用途 · Purpose

把患者的医生们（中国与其他国家）已经提出的治疗方案并排列出：每个方案包含什么、周期、需要几次行程、来自书面报价的费用区间、需要问医生的问题。它整理选项，不排序、不推荐。

Put the options a patient's doctors have proposed, in China and elsewhere, side by side: what each involves, duration, trips needed, cost ranges from written quotes and questions to ask. It organises options without ranking or recommending.

何时使用 · When to use

  • 患者拿到两个以上方案、难以取舍时
  • 患者想知道中国方案与本国方案的差别时
  • 第二意见返回后

输入 · Inputs

字段 Field 说明 Description 必需 Required
options 各方案来源（医生/医院）、内容、周期 是
quotes 书面报价（来自 cost-estimate） 否
patient_priorities 患者看重的因素：时间、费用、语言、距离家人 是

步骤 · Steps

  1. 只收录医生提出的方案，每个注明来源与日期；患者自己听说的方案标注"未经医生提出"。
  2. 逐项对齐：方案内容、周期、住院天数、行程次数、随访要求、费用区间（只用书面报价）。
  3. 按患者看重的因素做对照，不打分、不排序。
  4. 问题清单：每个方案需要问医生的问题（适应条件、风险、证据）。
  5. 涉及疗效与风险的比较，一律写"请向医生确认"。

输出格式 · Output format

【方案对照 / Side by side】
| 维度 | 方案 A | 方案 B |
【与患者优先事项的关系 / Against your priorities】
【问医生的问题 / Questions】
【说明】方案选择由患者与医生共同决定

边界与禁止事项 · Boundaries

  • 不推荐、不排序方案，不比较疗效优劣。
  • 不收录没有医生提出的方案作为选项。
  • 费用只用书面报价。

医学声明 · Disclaimer

本 Skill 仅提供信息整理与流程支持，不构成医疗建议，诊断与治疗决定以执业医生意见为准。This Skill organises information and supports workflows only; it is not medical advice. Diagnosis and treatment decisions rest with licensed physicians.

示例 · Examples

示例 1：前列腺癌两个方案的对照

虚构病例 / Fictional case

输入 Input

  • options: 方案 A（本国医生，2026-10）：根治性前列腺切除；方案 B（中国医生远程会诊，2026-11）：放射治疗
  • quotes: 方案 B 医院报价 120,000–150,000 CNY
  • patient_priorities: 治疗总时间、离家时间

输出 Output

【方案对照 / Side by side】
| 维度 | 方案 A：手术（本国） | 方案 B：放疗（中国） |
|---|---|---|
| 来源 | 本国泌尿外科，2026-10 | 中国放疗科远程会诊，2026-11 |
| 治疗周期 | 以医生说明为准 | 以医生说明为准（放疗通常分多次进行） |
| 离家时间 | 本国就医 | 需在华停留整个疗程 |
| 费用 | 本国医保或自费，向本国医院索取 | 120,000–150,000 CNY（书面报价） |

【问医生的问题 / Questions】
1. 我的分期与身体情况更适合哪种方式？各自的主要风险？
2. 放疗的具体次数与周期？能否部分在本国完成？
3. 两种方式之后的随访安排？

【说明】方案选择由患者与医生共同决定
示例 2：患者听说的方案

虚构病例 / Fictional case

输入 Input

  • options: 方案 A（中国医生）：标准化疗；患者在网上看到某"新疗法"
  • patient_priorities: 效果

输出 Output

【方案对照 / Side by side】
| 维度 | 方案 A：标准化疗 | 网上看到的疗法 |
|---|---|---|
| 来源 | 中国肿瘤科医生，2026-11 | 未经医生提出 |

【问医生的问题 / Questions】请主治医生评估网上看到的疗法是否适用于您、是否有获批或临床试验途径
【说明】未经医生提出的方案不作为选项比较
