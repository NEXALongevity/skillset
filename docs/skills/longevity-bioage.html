长寿与生物年龄评估 · Longevity & Biological Age Assessment

用途 · Purpose

为长寿医学和高端体检客户组织评估流程：收集生物标志物与生活方式数据，说明已发表的生物年龄算法及其局限，生成给评估医生的结构化报告。生物年龄只是研究性指标，不是诊断。

Organise a longevity assessment for longevity and premium check-up clients: collect biomarkers and lifestyle data, explain published biological-age methods and their limits, and prepare a structured report for the reviewing physician. Biological age is a research metric, not a diagnosis.

何时使用 · When to use

  • 客户咨询抗衰、长寿项目时
  • 体检后希望了解"生物年龄"时
  • 长寿项目前后对比时

输入 · Inputs

字段 Field 说明 Description 必需 Required
chronological_age 实际年龄 是
biomarkers 已有化验结果（含单位与检测日期） 是
method 拟用的算法（如基于常规血液指标的表型年龄、表观遗传时钟），需有文献出处 否
lifestyle 睡眠、运动、饮食、吸烟饮酒 否

步骤 · Steps

  1. 方法说明：列出可选的生物年龄方法、所需指标、文献出处和局限（人群来源、实验室差异、不能用于个体诊断）。
  2. 数据核对：检查所需指标是否齐全、单位是否与方法一致、检测日期是否接近。缺项不估算。
  3. 计算：只有在使用已发表公式且指标齐全时才计算；公式与系数从原文献获取并写明出处，不凭记忆。
  4. 报告：给医生的报告包括原始数据、计算结果、方法局限；给客户的说明强调"研究性指标，变化趋势比单次数值更有意义"。
  5. 医生给出干预建议后，交给 nutrition-exercise 等执行。

输出格式 · Output format

【方法 / Method】名称、文献、所需指标、局限
【数据核对 / Data check】
| 指标 | 数值 | 单位 | 日期 | 状态 |
【结果 / Result】（仅在条件满足时）
【给客户的说明 / Client note】
【待医生审阅 / For physician review】

边界与禁止事项 · Boundaries

  • 生物年龄不是诊断，不用来判断疾病或寿命。
  • 不使用来源不明的算法；缺少指标时不估算。
  • 不推荐未经批准的抗衰药物、干细胞或其他未获批疗法。
  • 宣传中不得出现"逆龄 X 岁"等承诺性表述。

示例 · Examples

示例 1：指标不全时的处理

虚构病例 / Fictional case

输入 Input

  • chronological_age: 56
  • biomarkers: 白蛋白、肌酐、血糖、C 反应蛋白、白细胞计数（缺淋巴细胞百分比、平均红细胞体积、红细胞分布宽度、碱性磷酸酶）
  • method: 基于常规血液指标的表型年龄（需写明文献）

输出 Output

【方法 / Method】基于常规血液指标的表型年龄方法；所需指标以原文献为准；局限：基于特定人群数据建立，实验室方法差异会影响结果，不能用于个体诊断

【数据核对 / Data check】
| 指标 | 状态 |
|---|---|
| 白蛋白、肌酐、血糖、C 反应蛋白、白细胞计数 | 已有 |
| 淋巴细胞百分比、平均红细胞体积、红细胞分布宽度、碱性磷酸酶 | 缺失 |

【结果 / Result】不计算：指标不全
【给客户的说明 / Client note】缺失的 4 项属于常规血常规和肝功能项目，下次抽血时一并检测即可
示例 2：长寿项目 6 个月前后对比

虚构病例 / Fictional case

输入 Input

  • chronological_age: 61
  • biomarkers: 两次完整指标，同一实验室，间隔 6 个月
  • lifestyle: 6 个月内开始规律运动、改善睡眠

输出 Output

【数据核对 / Data check】两次检测同一实验室、指标齐全、单位一致：可比

【结果 / Result】
| 时间 | 实际年龄 | 计算结果 |
|---|---|---|
| 基线 | 61 | 按文献公式计算后填写 |
| 6 个月 | 61.5 | 按文献公式计算后填写 |

【给客户的说明 / Client note】这是研究性指标。单次变化可能受测量误差影响，建议结合医生意见、看长期趋势
【待医生审阅 / For physician review】原始数据、两次结果、生活方式变化记录
