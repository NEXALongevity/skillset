营养与运动 · Nutrition & Exercise Planning

用途 · Purpose

把医生或营养师的建议落成可执行的一周饮食与运动计划，兼顾患者的饮食文化、宗教禁忌和在华期间能买到的食物。它执行医嘱，不自行开处方式的饮食或运动方案。

Turn a doctor's or dietitian's recommendations into a practical weekly meal and activity plan that respects the patient's food culture, religious restrictions and what is available in China. It implements recommendations; it does not prescribe.

何时使用 · When to use

  • 术后恢复期、出院时医生给出饮食或活动要求后
  • 体检或长寿评估后，医生建议调整生活方式时
  • 患者在华长期停留、需要适应当地饮食时

输入 · Inputs

字段 Field 说明 Description 必需 Required
recommendations 医生或营养师的书面建议 是
restrictions 过敏、宗教饮食（如清真）、素食等 是
location 所在城市与住宿条件（能否做饭） 否
activity_level 当前活动能力与限制 是

步骤 · Steps

  1. 提取约束：从建议中列出硬性要求（如低盐、软食、禁止负重）和目标。
  2. 饮食计划：按一周排餐，标注在当地容易买到的食物；清真、素食等要求优先满足；在中国外出就餐时给出点餐说明卡。
  3. 运动计划：只使用医生允许的活动类型和强度；术后计划写明"由康复医师确认后再进阶"。
  4. 安全提示：列出应停止运动并联系医生的情况。
  5. 复盘：每周记录执行情况，交给 chronic-care-followup 或医生。

输出格式 · Output format

【约束 / Constraints】
【一周饮食 / Weekly meals】
【点餐卡 / Ordering card】（患者语言 + 中文）
【活动计划 / Activity】
【停止信号 / Stop and call】

边界与禁止事项 · Boundaries

  • 不设定热量、营养素或运动强度的具体处方，除非来自医生或营养师。
  • 不推荐保健品；涉及保健品时交给 drug-supplement-interactions。
  • 不承诺减重、逆转疾病等效果。

示例 · Examples

示例 1：清真饮食患者胃部手术后在华恢复

虚构病例 / Fictional case

输入 Input

  • recommendations: 医生：少量多餐，软食，避免辛辣，术后 4 周内不提重物
  • restrictions: 清真
  • location: 上海，酒店式公寓可做饭
  • activity_level: 可室内行走

输出 Output

【约束 / Constraints】少量多餐；软食；清真；避免辛辣；4 周内不提重物

【一周饮食 / Weekly meals】（示例两天）
| 时间 | 第 1 天 | 第 2 天 |
|---|---|---|
| 早 | 小米粥、蒸蛋 | 燕麦粥、香蕉 |
| 加餐 | 酸奶（清真认证） | 蒸南瓜 |
| 午 | 清炖牛肉（清真餐厅外带，去辣）、软米饭 | 鸡肉末豆腐羹 |
| 晚 | 番茄鸡蛋面（少油） | 鱼片粥 |

【点餐卡 / Ordering card】
请不要放辣椒，少油少盐，做软一点。我只吃清真食品。

【活动计划 / Activity】每天室内或小区平地散步，按医生允许逐步增加；不提超过医生规定重量的物品
【停止信号 / Stop and call】腹痛加重、发热、呕吐、黑便时立即联系医生
示例 2：长寿评估后的生活方式计划

虚构病例 / Fictional case

输入 Input

  • recommendations: 医生：每周至少 150 分钟中等强度有氧运动，加 2 次力量训练；减少精制糖
  • restrictions: 无
  • activity_level: 久坐，无运动禁忌（医生确认）

输出 Output

【约束 / Constraints】每周 ≥150 分钟中等强度有氧 + 2 次力量训练（医生建议）；减少精制糖

【活动计划 / Activity】
| 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
|---|---|---|---|---|---|---|
| 快走 30 分钟 | 力量训练 | 快走 30 分钟 | 休息 | 快走 30 分钟 | 力量训练 + 快走 30 分钟 | 骑行 30 分钟 |

【一周饮食 / Weekly meals】含糖饮料换成无糖茶或水；早餐加入蛋白质来源
【停止信号 / Stop and call】胸痛、明显气促、头晕时停止并就医
