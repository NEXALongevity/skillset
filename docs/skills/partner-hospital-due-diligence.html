合作医院尽职调查 · Partner Hospital Due Diligence

用途 · Purpose

新合作医院或诊所上线前，按统一清单做尽职调查：执业许可与诊疗科目、医生资质抽查、国际服务能力、价格透明度、投诉与纠纷处理、病历与数据管理、实地考察记录。每项写明来源与日期，形成可复核的档案。

Before onboarding a partner hospital or clinic, run one checklist: licence and approved scope, spot checks on doctors, international services, pricing transparency, complaint handling, records and data practices, and site-visit notes, each with source and date.

何时使用 · When to use

  • 签合作协议前
  • 合作满 12 个月复核时
  • 出现投诉或负面信息时

输入 · Inputs

字段 Field 说明 Description 必需 Required
facility 机构名称与城市 是
type 公立 / 民营 / 外资 是
services 拟合作的服务方向 是
site_visit 是否已实地考察 否

步骤 · Steps

  1. 资质：用 credential-verification 核验执业许可、诊疗科目（医美核对医疗美容科目）。
  2. 医生抽查：拟合作方向的主要医生，抽查执业注册。
  3. 国际服务：国际部、外语能力、口译、国际支付与保险直付。
  4. 价格透明：是否提供书面报价与明细、预交金与退款规则。
  5. 质量与投诉：公开的行政处罚信息（所在地卫健委、市场监管公开渠道）、投诉处理流程。
  6. 数据：病历传输方式、对跨境数据的处理与同意。
  7. 实地考察：环境、流程、接待能力，照片存档。
  8. 结论与复核日期。

输出格式 · Output format

【机构 / Facility】
【检查表 / Checklist】
| 维度 | 检查项 | 来源 | 日期 | 结果 |
【风险 / Risks】
【结论 / Result】通过 / 有条件通过 / 不通过；下次复核日期

边界与禁止事项 · Boundaries

  • 只记录可查证的事实，不传播未经核实的负面传闻。
  • 查不到的信息写"未查到"。
  • 结论供内部决策，不对外公开评级。

示例 · Examples

示例 1：民营生殖中心尽调

虚构内容 / Fictional content

输入 Input

  • facility: 某市民营生殖医学中心（虚构）
  • type: 民营
  • services: 辅助生殖
  • site_visit: 已考察

输出 Output

【检查表 / Checklist】
| 维度 | 检查项 | 来源 | 日期 | 结果 |
|---|---|---|---|---|
| 资质 | 执业许可 | 所在地卫健委公开查询 | 2026-11-27 | 一致 |
| 资质 | 辅助生殖技术批准 | 省级卫健委公布名单 | 2026-11-27 | 待核（需查最新名单） |
| 医生 | 3 名主诊医生执业注册 | 国家卫生健康委政务服务平台 | 2026-11-27 | 3/3 一致 |
| 价格 | 书面报价与明细 | 机构提供 | 2026-11-20 | 有，药费单列 |
| 质量 | 行政处罚公开信息 | 所在地卫健委、市场监管公开渠道 | 2026-11-27 | 未查到 |
| 数据 | 病历跨境传输同意流程 | 机构访谈 | 2026-11-20 | 无书面流程 |

【风险 / Risks】辅助生殖技术批准需核实；数据同意流程缺失
【结论 / Result】有条件通过：补齐两项后签约；下次复核 2027-11
示例 2：合作满一年复核

虚构内容 / Fictional content

输入 Input

  • facility: 已合作的某三甲医院国际医疗部
  • type: 公立
  • services: 肿瘤、心血管

输出 Output

【检查表 / Checklist】
| 维度 | 检查项 | 结果 |
|---|---|---|
| 资质 | 执业许可、科目 | 无变化 |
| 国际服务 | 国际部联系人 | 已更换，更新知识库 |
| 质量 | 本年度 NEXA 患者投诉 | 2 起，均已处理（见 case-review） |

【结论 / Result】通过；下次复核 2027-11
